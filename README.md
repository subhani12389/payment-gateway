# 💳 Payment Gateway Backend (Node.js + PostgreSQL)

A simplified payment gateway backend inspired by Razorpay / Stripe.
Supports merchants, orders, and payment capture with API authentication.

---

## 🚀 Features

### ✅ Implemented
- Health check API
- API Key & Secret authentication
- Create & fetch orders
- Capture payments (UPI)
- Prevent duplicate payments per order
- PostgreSQL persistence
- Dockerized services

### ⏳ Planned
- Refunds (schema created, API pending)

---

## 🧱 Tech Stack
- Node.js (Express)
- PostgreSQL
- Docker & Docker Compose
- REST APIs
